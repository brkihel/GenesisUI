# Roteiro R-057 — Criação: detalhes à esquerda, Criar | Aprimorar

| Campo | Valor |
|---|---|
| Pacote | `GenesisMods-GenesisUI-0.7.0-preview.14.zip` (inclui as correções do preview.13) |
| Pré-requisito | Perfil `test`; alguns materiais e um item aprimorável (ex.: machado). |

| # | Faça | Esperado | Se for diferente, envie |
|---|---|---|---|
| 1 | Na bancada, abra o inventário e vá para Criação. | Nada do vanilla por baixo. Detalhes à esquerda; à direita busca, categorias e as colunas Criar e Aprimorar separadas por uma linha fina. | Print. |
| 2 | Clique numa receita de Criar. | Detalhes mostram ícone, nome, tipo, descrição, tabela e materiais "tenho / preciso". Com material faltando: texto vermelho "Falta: …" e botão apagado. | Print. |
| 3 | Clique num item em Aprimorar. | Tipo mostra "Nível N → N+1"; a tabela mostra valores atuais → próximos em verde; o botão vira Aprimorar. | Print. |
| 4 | Crie algo com o botão; depois segure Shift e clique Criar num item de pilha (ex.: flechas). | Criação normal; com Shift cria vários, como no jogo. Materiais descontados certo. | Quantidades antes/depois. |
| 5 | Sem estação: vá para Criação. | Coluna Aprimorar explica que precisa de estação; Criar lista as receitas de mão. | Print. |
| 6 | Pegue materiais com a janela aberta (ou largue alguns). | Em até 1 s a lista reordena: o que dá para fazer sobe; o resto esmaece com "Faltam materiais". | — |
| 7 | Barra de dicas na Criação. | Esc Fechar, Selecionar, Shift + clique Criar vários, Q/E Abas. No Inventário, as dicas do inventário. | Print. |
| 8 | Pegue uma peça nova (ex.: construa uma bancada perto de materiais) para disparar "Nova peça para construção". | Aparece como cartão do GenesisUI (título dourado, nome, ícone), não o painel vanilla. | Print. |
| 9 | Veja os detalhes de um Porrete. | Sem "Armadura" (só dano/bloqueio). | Print. |
