## Reported, with the proven cause

1. **Top bar looks stretched** (ornaments). Jötunn's GUI canvases use
   `CanvasScaler.referencePixelsPerUnit = 50` (`GUIManager.CreateCustomGUI`), the HUD's canvas does
   not, and 9-slice borders scale with it: the shell's bars drew their end caps at another size.
   Fix: `Frame.CanvasScale` compensates by the canvas's reference relative to the HUD's; the shell
   logs the factor.
2. **HUD over the windows**: bars, hotbar and vanilla's key hints stayed on screen with the
   inventory open. Fix: the shell fades the HUD root and vanilla's key hints out while a window is
   open, and back in on close.
3. **"GENESISUI" in the bar**: unwanted (belongs in the mod's settings, F4.4). Removed.
4. **Map tab**: Q/E stopped working once the large map was open. Fix: a map opened from the tab
   returns to the tabs with Q/E (the map becomes a real tab in F6).
5. **Minimap top plate** must be the same element as the biome plate and sit over the ring. Done.
6. **Status tiles too far apart**: cell width 84 → 70.
7. **Colours still too bright**: tone darkened (D-029 ramp at 0.62, no extra saturation).
8. **Hotbar too heavy** (thick lines, many ornaments): replaced by eight single thin slots from
   window sheet 3, no plate; selected = lit thin slot, equipped = the same in green; food slots too.
