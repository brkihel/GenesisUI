## Bugs, with the proven cause

1. **Striped vital bars after a fault injection + retry** (print). `ModuleHost.Build` asks for
   an immediate refresh with `SinceRefresh = float.MaxValue`, and that value was passed as the
   elapsed time. `VitalBarView` added it to its animation clock: `sin(MaxValue * 1.3)` is NaN,
   so every drifting layer got NaN UVs. At first load the same refresh ran before the player
   existed, so it never reached the bars. Fix: the host never passes more than 0.25 s.
2. **Low-health effect**: the halo was hard to notice and drew a red box around the bar (print;
   a 9-sliced halo around a pointed frame). Fix: no halo; the frame itself pulses fully red.
3. **Interaction card over the open large map** (Vegvísir, print): vanilla keeps its hover
   text while the map covers it; our HUD root was the last sibling of the vanilla HUD root.
   Fix: the card hides while the large map is open, and the HUD root is placed before the large
   map's branch when both share the vanilla root (logged either way).
