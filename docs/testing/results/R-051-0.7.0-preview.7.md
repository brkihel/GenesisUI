# R-051 — Feedback on 0.7.0-preview.7

Diego reports that the equipment panel is functioning as intended. He found two window
lifecycle defects:

1. On the first inventory opening, the footer shortcut hints pile up in the middle and
   overlap one another. The footer used nested layout groups plus size fitters whose
   dimensions were unresolved on Unity's first canvas pass.
2. When closing the inventory, the vanilla window appears briefly before disappearing.
   `InventoryGui.IsVisible()` turns false after two hidden frames, while the vanilla close
   animation is still drawing; `win.inventory` restored vanilla graphics immediately.

The full R-051 item-safety matrix was not detailed in this report, so F4.2b remains in
client test. Preview.8 changes the hint layout and delays restoration through the close.
