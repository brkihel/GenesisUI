# R-068 — Release 1.1.2 modpack feedback

2026-10-04. Diego requested the first modular inventory integrations and reported:

- Jewelcrafting's Gemcutter's Table shows gem cutting, but its Socket tab and gem placement
  are inaccessible in GenesisUI.
- Backpack (including Adventurer Backpacks when installed), ring, necklace and HipLantern
  equipment cells are missing. Backpack contents should appear below the player's inventory.
- Diego clarified one native Coins wallet and two native key cells above the character.
  Backpack/lantern join aligned equipment columns; necklace/ring sit below the character.
- The test profile is Gale `GenesisHeimLocal`; Backpacks 1.3.10, Jewelcrafting 2.0.10 and
  HipLantern 1.1.12 DLL hashes match the local FullPlaythrough study copies. Adventure
  Backpacks is absent there; optional 2.0.3 contracts use the official download only.
- Inventory hover tooltips still use vanilla styling; use discreet gold borders and preserve
  foreign tooltip information.
- Backpack tooltip says "Press [E] to open", but E switches the shell tab.
- Desktop `bug visual barras.jpg` shows a large rounded rectangle around the vital bars and food.

## Proven source causes

`ClimateModule` targets its rectangular EdgeLight at `VitalsModule.VisualAnchor`, the entire
150 x 260 group, instead of the shaped bar art. This explains the rectangular rested halo.
`InventoryTabKeyPatch` clears Use before native inventory Update; WindowShellModule also reads
E directly to cycle tabs. Backpacks 1.3.10 reads Use in its container bridge, so this command
cannot reach that mod. Its bridge also hit-tests the hidden native grid by screen position.

The shipped inventory container view requires `m_currentContainer != null`. Backpacks instead
publishes a live inventory on the native container grid with its own ItemContainer bridge;
the real Container remains null. Dedicated foreign projection is required.

## Scope

This records user feedback before code changes. No new game run, F8 report, performance
measurement or modpack certification is claimed. Screenshot remains outside the repository.
